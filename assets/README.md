# Local character and voice assets

Copy the already-created `our_avatar/assets/ours-photoreal.glb` into this folder as `assets/ours-photoreal.glb`.

It is intentionally **not** included in Git: the technical audit described an approximately 25.55 MB MakeHuman/MPFB character with 52 ARKit facial targets and 15 visemes. Keep the original source, reference materials, and license/provenance documents in the original project.

Supply a **real spoken PCM WAV** as `assets/voice.wav` (or pass an absolute path). Do not confuse a generated test tone with intelligible narration.
