# LIVYNTH M001 — First Living Human

**Target:** one 12–15-second, 1080×1920, 30 fps talking-human MP4 from a photorealistic GLB, a real PCM WAV recording, and its transcript. No skeleton rebuild is necessary for a stationary presenter; the source face already contains facial morph targets.

## External foundation audit

The attached `our_avatar` technical audit measured `assets/ours-photoreal.glb` at about 25.55 MB with 52 ARKit face morphs and 15 Meta speech visemes. It reports **zero bones, skins, animations, or local video-rendering path**. Blender 4.5.10 can render MPEG4/H264 with its bundled FFmpeg; external `ffmpeg` is not installed on the author's Windows PATH. These are **report findings**, not independent checks on this empty LIVYNTH repository.

## Commands (Windows PowerShell)

```powershell
# Install Python 3.10+ and Blender 4.5, and copy the source GLB to assets/.
python -m unittest discover -s tests -v
python video/model_check.py --glb assets/ours-photoreal.glb

# Prepare a real spoken PCM WAV recording, with the exact transcript.
python video/build_video.py --glb assets/ours-photoreal.glb --audio assets/voice.wav --text "Welcome to Livynth. Imagination comes alive here." --preview

# Review output/livynth_m001.png, then omit --preview for the full MP4.
python video/build_video.py --glb assets/ours-photoreal.glb --audio assets/voice.wav --text "Welcome to Livynth. Imagination comes alive here."
```

If Blender is not on PATH, append `--blender "C:\\Program Files\\Blender Foundation\\Blender 4.5\\blender.exe"`.

## Word timing format (optional)

```json
[{"text":"Hello","start":0.25,"end":0.64},{"text":"world","start":0.67,"end":1.10}]
```

The numbers are seconds from the start of the PCM WAV. Supply this file with `--words-json path/to/words.json` to improve word placement.
