# LIVYNTH M001 — First Living Human

**Target:** one 12–15-second, 1080×1920, 30 fps talking-human MP4 from a photorealistic GLB, a real PCM WAV recording, and its transcript. No skeleton rebuild is necessary for a stationary presenter; the source face already contains facial morph targets.

## External foundation audit

The attached `our_avatar` technical audit measured `assets/ours-photoreal.glb` at about 25.55 MB with 52 ARKit face morphs and 15 Meta speech visemes. It reports **zero bones, skins, animations, or local video-rendering path**. Blender 4.5.10 can render MPEG4/H264 with its bundled FFmpeg; external `ffmpeg` is not installed on the author's Windows PATH. These are **report findings**, not independent checks on this empty LIVYNTH repository.

## Portrait-quality checkpoint (M001.1)

The first true 1080×1920 Blender still rendered successfully on the user's Windows 4.5.10 installation. It exposed three practical issues: the shot shows too much torso, skin/eyes are overly bright, and a full 420-frame render would be expensive. We now test framing and expressions before committing to a long MP4.

`render_talk.py` supports a reversible **studio** preset:

- Higher/tighter head-and-shoulders orthographic camera, reduced light energy and exposure.
- Neutral slate background with emission, so backdrop stays stable.
- A **material-only fitted shirt placeholder** on `base.001` below the neckline. This is *not cloth geometry* or a production garment. The source GLB remains untouched.
- 50%-resolution, 16-sample preview settings by default (final video retains 100% resolution and 32 samples).
- Four frames in a single Blender session: neutral, half-blink, full-blink, smile.

Run from the repo root in Windows PowerShell (on the feature branch):

```powershell
git pull --ff-only
$transcript = (Get-Content .\assets\voice_transcript.txt -Raw).Trim()
python tools/local_check.py --glb .\assets\ours-photoreal.glb --audio .\assets\voice.wav --text "$transcript" --preview-set
```

Expected artifacts (at default 540×960 resolution):
`output/livynth_m001_neutral.png`, `output/livynth_m001_half_blink.png`,
`output/livynth_m001_full_blink.png`, `output/livynth_m001_smile.png`.

Inspect all four for clipping, shirt boundary, eye and lash deformation, and mouth shape. If a face appears too high/cropped or shirt looks synthetic, treat it as a QA failure and refine the **reversible** studio preset—not the source GLB.

After those images pass, a cheap one-second audio/video smoke test is available:

```powershell
python video/build_video.py --glb .\assets\ours-photoreal.glb --audio .\assets\voice.wav --text "$transcript" --blender "C:\Program Files\Blender Foundation\Blender 4.5\blender.exe" --max-frames 30 --out output\livynth_smoke.mp4
```

The `--max-frames 30` test renders the first 30 frames (one second at 30fps) and uses the reduced preview samples and 50% resolution. **Do not render all 420 frames** until the smoke output is verified to contain visible animation and audible narration.

To compare with the original image, use `--preset legacy --preview` in `video/build_video.py`; this preserves the original camera/lighting and disables the placeholder shirt.

### Review criteria

- Subject head and shoulders fully visible; forehead/hair not clipped.
- Upper torso covered in the debug presentation, without accidental recoloring of face/neck.
- Eye closure is symmetrical and eyebrow/lash artifacts do not spike.
- Smile moves the mouth and cheeks instead of stretching unrelated parts.
- Short MP4 has recognizable video frames and spoken audio in sync.
- Render time measured on the user's hardware; avoid guessing from Python-only tests.
